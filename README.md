# Mi Portfolio - Facundo Jesús Citera 🏗️💻

Bienvenido al repositorio de mi portafolio personal. Este sitio web es mi carta de presentación interactiva, donde exhibo mi trayectoria, formación académica y proyectos destacados en dos disciplinas que me apasionan: **Arquitectura** y **Programación**.

🔗 **[Visitar el Portafolio en Vivo](https://facundojesus.github.io/mi-portfolio/)** *(Enlace de despliegue)*

## 🚀 Sobre el Proyecto

Este sitio web es completamente estático y fue desarrollado para ser rápido, accesible y visualmente atractivo. Está diseñado para mostrar de forma organizada mis dos perfiles profesionales:

## 🛠️ Tecnologías Utilizadas

- **HTML5 & CSS3**: Para la estructura semántica y los estilos personalizados.
- **JavaScript (Vanilla)**: Lógica de la interfaz, animaciones (efecto máquina de escribir) y uso de **Web Components** (como `<site-nav>`) para mantener el código modular y evitar la repetición en las múltiples páginas.
- **Bootstrap 5**: Framework de CSS utilizado para crear un diseño responsive mediante un sistema de grillas y componentes modulares (como Modals y Cards).
- **EmailJS**: Integrado para el formulario de la sección "Contacto", permitiendo enviar correos directamente desde el cliente.
- **FontAwesome & Google Fonts**: Iconografía vectorial escalable y tipografías personalizadas (`Abel`, `Arvo`, `Ubuntu`, etc.).

## 📁 Estructura del Proyecto

El sitio está estructurado en torno a un archivo principal (`index.html`) que contiene la información central "Sobre Mí", desde el cual se puede navegar a las subsecciones temáticas a través de la barra de navegación modular.

- **`/imgs`**: Contiene todas las imágenes estáticas organizadas por categorías (fotos de perfil, plataformas de cursos, certificados, miniaturas de proyectos).
- **`styles.css`**: Hoja de estilos principal con toda la personalización estética.
- **`nav.js`**: Web Component que inyecta dinámicamente la barra de navegación `<nav>` en todas las vistas HTML, resolviendo las rutas de forma automática independientemente de la profundidad de la carpeta.
- **`*.html`**: Las múltiples páginas organizadas en áreas (experiencia laboral, certificaciones, proyectos) tanto para el ámbito de arquitectura como de programación.
